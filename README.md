Number Guessing Game in Python

A fun and interactive Number Guessing Game developed using Python. The game allows players to guess a randomly generated number with different difficulty levels and also supports 2-player mode.

 Features
- Single Player Mode
-  Two Player Mode
-  Easy Level
-  Medium Level
-  Hard Level
-  Higher/Lower hints
-  Score system
-  Play Again option
-  Input validation
-  Random number generation

 Difficulty Levels
Level| Range| Attempts
Easy| 1–50| 10
Medium| 1–100| 7
Hard| 1–200| 5

 Technologies Used

- Python 3
- "random" module

 Python Concepts

This project demonstrates:

- Variables
- Data types
- "input()" and "print()"
- Conditional statements
- "for" and "while" loops
- Functions
- User input validation
- Random number generation
- Operators
